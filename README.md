## What is this?

A free, browser-based practice quiz simulator to help you revise for the **Apple Deployment & Management** exam. It was built as a personal study aid and shared openly so others can benefit too.

- ✅ 80 practice questions covering core exam topics
- ✅ Questions are randomised every time you start
- ✅ Multi-select questions (choose 2) are fully supported
- ✅ Instant feedback and explanations after every answer
- ✅ Full review of all answers at the end
- ✅ No login, no ads, no tracking — just open and use

---

## Want to use your own questions?

This project is intentionally open. You can:

1. Download or fork this repo
2. Open `questions.js`
3. Add, remove, or edit questions in your own words
4. Host it yourself for free on GitHub Pages

The questions in this repo are written in my own words for personal revision purposes. Please do the same — rephrase questions in your own words rather than copying verbatim from any official study materials.
